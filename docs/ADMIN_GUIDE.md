# Platform owner & admin guide

**Getting in.** Sign up with profjero947@gmail.com and verify the email. You get the owner and platform-admin roles automatically. Use the workspace switcher (top of the sidebar) → **Platform console**.

**Daily checks** (Overview shows a "Needs your attention" box): school applications, courses in review, instructor applications and open tickets.

**Schools.** Schools → Pending → read the details → Approve (the applicant becomes school admin) or Reject with a reason (it's sent to them). Suspend or reinstate later. Grant **EduPro for Schools** from an approved school's card.

**Instructors.** Teachers → Applications → Approve to grant the independent instructor role.

**Courses.** Courses & content → filter "In review" → open the course (you can preview it) → Publish or Request changes. Use "Make EduPro course" to mark premium content.

**Users.** Search, then use the ⋯ menu: Manage roles (only the owner can add or remove platform admins), Grant EduPro, Suspend or Reactivate. The owner can't be suspended.

**Edu / EduPro.** Plans & features is a matrix of features × plans. Toggle features and set limits (empty = unlimited). Changes apply immediately. Keep the free plans genuinely useful. Grants are for pilots; payments are not connected.

**Content & community.** Categories, platform announcements (sent to everyone, so use sparingly), certificates (revoke with a reason, shown on the verification page), live classes overview.

**Support.** Support desk: assign to yourself, reply, add internal notes and change status. Contact inbox: messages from the public form.

**Audit log.** Every privileged action, permanent and read-only.

**Settings.** Public JSON settings. Add `home.testimonials` (array of `{quote, name, role}`) only with genuine, permitted testimonials.
