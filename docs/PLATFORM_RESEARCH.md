# What we adopted from the best learning platforms

You asked for "the best from systems ever". These are the patterns that make leading platforms succeed, and where each lives in ProfJero Edu. All of them are original implementations; nothing is copied from those products.

| Proven pattern | Seen in | ProfJero Edu |
|---|---|---|
| Class stream + teacher announcements | Google Classroom, Schoology | Class board (chalkboard), class discussion, announcements per course/class/school |
| Modules → lessons → activities, completion rules | Canvas, Moodle | Curriculum editor, rule-based lesson completion (mark complete / pass quiz / submit work) |
| Short practical lessons with instant checks | Khan Academy, Coursera | Block lessons with code+output, activities, knowledge checks, steps, embeds |
| Question banks, randomisation, server timers | Moodle, Canvas Quizzes | 9 question types, shuffling, attempt limits, server-enforced time, result release rules |
| Rubrics + return for correction | Canvas SpeedGrader, Turnitin | Rubric criteria, grade dialog, return/resubmit workflow |
| Visible progress and streaks for motivation | Duolingo, Khan Academy | Progress rings, 8-week activity heatmap, active-day counts (no surveillance) |
| Verifiable credentials | Coursera, Credly | Certificates with a public verification URL |
| Live classes via existing tools | Google Classroom + Meet, Teams Education | Provider-agnostic scheduling with one-tap Join and attendance |
| Presence and raise-hand | Zoom, ClassDojo | Realtime "In class now", raise hand, teacher "Answer"/"Lower all", "classmates studying this lesson" |
| Roll call and attendance | School MIS systems | Daily register per class, live-session attendance |
| Bulk onboarding with error reports | Google Workspace for Education | CSV import with per-row report, invitations that avoid duplicate accounts |
| Offline-first learning | Kolibri, Kiwix | PWA, offline lessons per user, queued progress sync |
| Free core, premium upgrade | Coursera, Duolingo | Central Edu/EduPro entitlements; individual, teacher and school scopes |
| Early-warning signals | Canvas analytics | "Falling behind" alerts, most-missed questions |

## Designing for a face-to-face feel
1. **A room per class.** Every course, class and live session has its own classroom with a teacher board, people present and a conversation.
2. **Presence.** Learners see who is in class and studying alongside them.
3. **A timetable.** Live classes appear like school periods with countdowns, reminders and Join buttons.
4. **Rituals.** Roll call, raise hand, teacher-pinned answers, marked work returned with comments.
